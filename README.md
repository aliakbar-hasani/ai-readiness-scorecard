# ai-readiness-scorecard

A short web assessment that helps business owners find where AI can save them time and money, with a ranked list of opportunities and rough ROI estimates.

## How it works

1. The owner answers about 10 questions on their processes and tools.
2. The app scores each area and returns a ranked list of AI opportunities with rough ROI.
3. An optional email capture leads to a workshop booking.

## Setup

```bash
cp .env.example .env   # then fill in real values; .env is git-ignored
```

## Status

Early stage: spec and question set first, then the scoring logic and results page.
